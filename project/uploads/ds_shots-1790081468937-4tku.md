# uxSmartBuy.md — architektura treści i specyfikacja UI

> Uzupełnia `startSmartBuy.md`. Tamten plik mówi **jak budować**, ten mówi **co użytkownik widzi i robi**.
> Zakres = MVP. Wszystko spoza MVP jest w sekcji 11 i nie trafia do UI (nawet jako wyszarzone „wkrótce”).

---

## 1. Zasady UX (rozstrzygają spory)

1. **Popup = nowe oferty.** Użytkownik otwiera rozszerzenie, żeby zobaczyć, co się pojawiło. Konfiguracja jest na drugim planie.
2. **Dodanie obserwacji w < 20 s.** Wymagane są tylko 2 pola, reszta ma rozsądne wartości domyślne.
3. **Jedna oferta = jedno powiadomienie.** Żadnych duplikatów, żadnego spamu. Lepiej przegapić mniej niż zasypać.
4. **Problem zawsze ma następny krok.** Każdy błąd mówi, co się stało i co zrobić.
5. **Zero żargonu.** „Obserwacja”, nie „watch job”. „Sprawdzaj co 15 min”, nie „interwał alarmu”.

## 2. Mapa aplikacji

```
Smart Buy
├─ Ikona w pasku (badge = liczba nowych ofert)
├─ POPUP (380 × 560 px)
│  ├─ Zakładka „Nowe”        ← domyślna
│  ├─ Zakładka „Obserwuję”
│  ├─ Formularz „Nowa obserwacja” (widok w popupie)
│  └─ Baner szybkiego dodawania (tylko na stronie wyników OLX/Vinted/Allegro)
├─ STRONA OPCJI (pełna karta)
│  ├─ Obserwacje   (lista + edycja + szczegóły z ofertami)
│  ├─ Oferty       (wszystkie znalezione, filtr po obserwacji/serwisie)
│  └─ Ustawienia   (e-mail, domyślne wartości, status serwisów, dane)
├─ ONBOARDING (1 ekran na stronie opcji, przy pierwszej instalacji)
├─ POWIADOMIENIE PRZEGLĄDARKI
└─ E-MAIL (pojedyncza oferta / zestawienie dzienne / alert o problemie)
```

Nawigacja: maks. 2 poziomy. Z każdego miejsca w popupie 1 klik do strony opcji (ikona ⚙).

## 3. Model treści

### 3.1 Obserwacja

| Pole | Wymagane | Domyślnie | Uwagi / walidacja |
|---|---|---|---|
| Nazwa | tak | — | 2–60 znaków. Pokazywana wszędzie jako tytuł. |
| Słowa kluczowe | tak | = nazwa | Chipy. Każdy chip to alternatywa (LUB). Maks. 10. |
| Serwisy | tak | wszystkie 3 | Min. 1. |
| Cena maks. | nie | puste | Liczba, PLN. |
| Cena min. | nie | puste | Pod „Więcej filtrów”. Min ≤ maks. |
| Wyklucz słowa | nie | puste | Chipy. Pod „Więcej filtrów”. Np. „uszkodzony”, „na części”. |
| Lokalizacja | nie | cała Polska | Pod „Więcej filtrów”. Miasto + promień (OLX/Allegro). |
| Stan | nie | dowolny | Nowy / Używany / Dowolny. |
| Rozmiar | nie | puste | Tekst, używany głównie przez Vinted. |
| Sprawdzaj co | tak | 15 min | Presety: 5 min · 15 min · 1 h · 6 h. Min. 5 min. |
| Powiadomienia | tak | przeglądarka: wł., e-mail: natychmiast | E-mail: Natychmiast / Raz dziennie / Wyłączony. |
| Status | system | Aktywna | Aktywna / Wstrzymana / Problem. |

Pola nieobsługiwane przez dany serwis są ignorowane dla tego serwisu (bez komunikatu w formularzu, informacja tylko w tooltipie „i”).

### 3.2 Oferta (znormalizowana, tylko do odczytu)

Zdjęcie (miniatura), tytuł, cena, serwis, lokalizacja, data dodania, link, obserwacja, która ją znalazła, stan: **Nowa / Widziana / Ukryta**.

- Klik w ofertę → otwiera link w nowej karcie i zmienia stan na Widziana.
- „Ukryj” → oferta znika z list i nigdy nie wraca (dedup po ID).
- Oferty starsze niż 30 dni są usuwane automatycznie.

### 3.3 Serwis

OLX, Vinted, Allegro. Stan: **Działa / Problem** (adapter zwraca błąd lub 0 wyników N razy z rzędu). Oznaczenie w UI: litera w neutralnym kółku (O / V / A), **bez logotypów i kolorów marek**.

## 4. Kluczowe flow

### F1. Pierwsze uruchomienie
Instalacja → otwiera się strona opcji z onboardingiem:
1. Jedno zdanie: „Smart Buy sprawdza OLX, Vinted i Allegro za Ciebie i daje znać, gdy pojawi się pasująca oferta.”
2. Pole e-mail (opcjonalne, „Pomiń” widoczne).
3. Przycisk „Dodaj pierwszą obserwację” → formularz.
4. Prośba o zgodę na powiadomienia **dopiero po zapisaniu pierwszej obserwacji** (wtedy ma sens).

### F2. Dodanie obserwacji (ręcznie)
Popup → „+ Obserwuj” → nazwa → (opcjonalnie cena maks.) → „Zacznij obserwować”
→ toast „Obserwujesz: {nazwa}. Pierwsze sprawdzenie trwa…” → pierwsze sprawdzenie od razu, nie po interwale.
Wyniki pierwszego sprawdzenia **nie wysyłają powiadomień** (to oferty już istniejące). Trafiają do zakładki „Nowe” z nagłówkiem „Już dostępne (12)”.

### F3. Szybkie dodanie z wyszukiwarki serwisu (zalecane do MVP)
Użytkownik jest na stronie wyników OLX/Vinted/Allegro → w popupie baner „Obserwuj to wyszukiwanie” → formularz wypełniony z URL (fraza, cena, lokalizacja, serwis) → „Zacznij obserwować”.
To najprostsza ścieżka, bo użytkownik ustawia filtry w znanym interfejsie serwisu.

### F4. Nowa oferta
Sprawdzenie → nowa pasująca oferta → badge +1 → powiadomienie → (e-mail wg ustawień).
Klik w powiadomienie → otwiera ofertę. Kilka ofert naraz z jednej obserwacji → **jedno** zbiorcze powiadomienie „5 nowych ofert: {nazwa}” → klik otwiera popup.

### F5. Problem z serwisem
Adapter padł → status serwisu „Problem” → obserwacje używające go dostają żółty znacznik → jeden baner w popupie i jeden e-mail (maks. raz na 24 h).
Pozostałe serwisy działają normalnie.

### F6. Wstrzymanie / edycja / usunięcie
Zakładka „Obserwuję” → przełącznik wł./wył. bezpośrednio na liście. Edycja i usuwanie w menu „⋯”. Usunięcie → toast z „Cofnij” (5 s), bez modala.

### 5.1 Popup — „Nowe” (domyślny)

```

│ Smart Buy                      ⚙     │
│ [ Nowe 4 ]  [ Obserwuję 3 ]          │
├──────────────────────────────────────┤
│ ┌──────────────────────────────────┐ │  ← baner F3, tylko na stronie serwisu
│ │ Obserwuj to wyszukiwanie    [+]  │ │
│ └──────────────────────────────────┘ │
│ Dziś                                 │
│ ┌────┐ Leica M6 czarna        4 200 zł│
│ │img │ (O) Kraków · 12 min temu      │
│ └────┘ Leica M6               [Ukryj]│
│ ┌────┐ Kurtka Arc'teryx M       380 zł│
│ │img │ (V) · 40 min temu             │
│ └────┘ Kurtka zimowa          [Ukryj]│
│ Wczoraj                              │
│ …                                    │
├──────────────────────────────────────┤
│ Oznacz wszystkie jako widziane       │

└──────────────────────────────────────┘
```

- Lista pogrupowana po dniu, najnowsze na górze. Nowe mają kropkę przy tytule.

- Trzecia linia (mniejsza, szara) = nazwa obserwacji.
- Otwarcie popupu **nie** zeruje badge. Zeruje go klik w ofertę albo „Oznacz wszystkie jako widziane”.

- Klik w wiersz → szczegóły obserwacji na stronie opcji (oferty tej obserwacji + edycja).

```
│                                      │
```

- Opcja e-mail wyszarzona z linkiem „Dodaj e-mail”, jeśli adres nie jest zweryfikowany.
- W edycji przycisk: „Zapisz zmiany”.

```
┌────────────┬─────────────────────────────────────────────┐
│ Smart Buy  │ Obserwacje                     [+ Obserwuj] │
│            │                                             │
│ Obserwacje │  tabela: Nazwa · Serwisy · Cena maks. ·     │
│ Oferty     │  Co ile · Nowe · Ostatnie sprawdzenie ·     │
│ Ustawienia │  Status · ⋯                                 │
│            │                                             │
│ ────────── │                                             │
│ Serwisy    │                                             │
│ ● OLX      │                                             │
│ ● Vinted   │                                             │
│ ● Allegro  │                                             │
└────────────┴─────────────────────────────────────────────┘
```
- Lewa kolumna: nawigacja + stałe mini-statusy serwisów (zielona/żółta kropka + tekst, nie sam kolor).
- **Szczegóły obserwacji:** nagłówek (nazwa, filtry jako czytelne zdanie: „Leica M6 do 5 000 zł, OLX i Allegro, co 15 min”), przyciski Edytuj · Sprawdź teraz · Wstrzymaj, poniżej lista ofert jak w 5.1.
- **Oferty:** ta sama lista co w popupie, szersza, z filtrami: obserwacja, serwis, stan (Nowe/Widziane/Ukryte).
- **Ustawienia:**
  - E-mail: adres + status weryfikacji + „Wyślij testowy e-mail”
  - Domyślne wartości nowej obserwacji: „Sprawdzaj co”, tryb e-mail, godzina zestawienia dziennego (domyślnie 8:00)
  - Serwisy: status, ostatnie udane sprawdzenie, liczba błędów
  - Dane: „Usuń wszystkie dane” (jedyny modal potwierdzenia w aplikacji)

```
Tytuł:   4 200 zł · Leica M6 czarna

Ikona:   miniatura oferty (fallback: ikona Smart Buy)
Przyciski: [Otwórz] [Ukryj]
```
Zbiorcze: `Tytuł: 5 nowych ofert · Leica M6`, `Treść: od 3 900 zł, OLX i Allegro`.

### 5.6 E-maile

| Typ | Temat | Treść |
|---|---|---|
| Natychmiast | `4 200 zł · Leica M6 czarna` | Karta oferty (zdjęcie, cena, serwis, lokalizacja, przycisk „Zobacz ofertę”) |

## 8. Design system

### 8.1 Kierunek
Narzędzie, które działa w tle i odzywa się tylko, gdy ma coś ważnego. Interfejs spokojny i grafitowy. **Jedyny mocny akcent to kolor „metki”** — zarezerwowany dla nowej oferty i ceny. Gdy użytkownik widzi ten kolor, wie, że jest coś nowego.

### 8.2 Kolory (tokeny)

| Token | Jasny | Ciemny | Użycie |
|---|---|---|---|
| `--bg` | `#FFFFFF` | `#16181D` | tło |
| `--surface` | `#F3F4F6` | `#1F2229` | wiersze hover, pola |
| `--ink` | `#1B1E24` | `#ECEDEF` | tekst główny, ceny |
| `--ink-muted` | `#646A75` | `#9BA1AB` | meta, trzecia linia |
| `--line` | `#E3E5E9` | `#2C3038` | separatory |
| `--tag` | `#F2C230` | `#F2C230` | kropka „nowa”, badge, zaznaczenie aktywnej zakładki |
| `--action` | `#2B4DD8` | `#7C95FF` | przyciski główne, linki |
| `--warn` | `#B26A00` | `#E0A13A` | problem z serwisem |
| `--danger` | `#C0362C` | `#F07167` | tylko „Usuń wszystkie dane” |

Kontrast tekstu min. 4.5:1. `--tag` nigdy jako kolor tekstu na białym (za niski kontrast) — tylko jako wypełnienie z tekstem `--ink`.

### 8.3 Typografia
- Krój: **Manrope** (zbundlowany lokalnie, wagi 400/600/700, zawiera polskie znaki). Fallback: `system-ui, sans-serif`.
- Ceny: `font-variant-numeric: tabular-nums`, waga 700.

| Rola | Rozmiar / wysokość linii | Waga |
|---|---|---|
| Tytuł ekranu | 16 / 22 | 700 |
| Tytuł oferty | 14 / 20 | 600 |
| Cena | 15 / 20 | 700 |
| Tekst | 13 / 18 | 400 |
| Meta | 12 / 16 | 400 |

### 8.4 Siatka i odstępy
- Skala: 4, 8, 12, 16, 24 px. Marginesy popupu 16 px.
- Wiersz oferty: 72 px, miniatura 56 × 56, zaokrąglenie 6 px.
- Promienie: pola i przyciski 8 px, chipy pełne (999 px), panele 12 px. Bez cieni w popupie; na stronie opcji tylko pod menu rozwijanym.
- Wszystko wyrównane do lewej, cena do prawej.

### 8.5 Komponenty (MVP)
`TopBar`, `Tabs` (z licznikiem), `OfferRow`, `WatchRow`, `SiteBadge` (O/V/A), `StatusDot`, `Toggle`, `ChipInput`, `SegmentedControl` (presety interwału), `Select`, `Checkbox`, `Button` (primary / secondary / ghost / danger), `Banner` (info / warn), `Toast` (z opcjonalnym „Cofnij”), `EmptyState`, `Skeleton`, `Disclosure` („Więcej filtrów”), `Modal` (jedno użycie).

### 8.6 Ruch
Tylko w odpowiedzi na akcję: wysunięcie formularza (150 ms), zniknięcie ukrytej oferty (collapse 150 ms), toast. Respektuj `prefers-reduced-motion`.

## 9. Dostępność i obsługa klawiaturą

- Cały popup obsługiwalny klawiaturą: Tab / Shift+Tab, Enter otwiera ofertę, `H` ukrywa zaznaczoną ofertę, `N` otwiera nową obserwację, strzałki przełączają zakładki.
- Widoczny fokus (2 px `--action`, offset 2 px).
- Status nigdy tylko kolorem: kropka + tekst lub ikona.
- `aria-live="polite"` dla toastów i licznika nowych ofert.
- Alt miniatury = tytuł oferty.
- Tryb ciemny wg `prefers-color-scheme`.

## 10. Kryteria akceptacji (Definition of Done dla UI)

- [ ] Nowa obserwacja da się dodać w ≤ 3 interakcjach (nazwa → Enter → gotowe).
- [ ] Pierwsze sprawdzenie startuje natychmiast i nie wysyła powiadomień.
- [ ] Żadna oferta nie pojawia się dwa razy (popup, powiadomienie, e-mail).
- [ ] Kilka ofert z jednego sprawdzenia = jedno powiadomienie zbiorcze.
- [ ] Każdy stan z sekcji 6 ma zaimplementowany widok i test.
- [ ] Wszystkie teksty pochodzą z jednego pliku `copy.pl.ts` (przygotowane pod tłumaczenie), zgodnie ze słownikiem z sekcji 7.
- [ ] Tokeny z sekcji 8 w jednym pliku `tokens.css`; zero kolorów wpisanych na sztywno w komponentach.
- [ ] Popup renderuje się w < 100 ms z lokalnych danych (bez czekania na sieć).
- [ ] Przejście testów klawiaturą i kontrastu (axe) bez błędów krytycznych.
- [ ] Jasny i ciemny motyw sprawdzone na wszystkich ekranach.

## 11. Poza zakresem UI MVP (nie projektuj, nie pokazuj)

Historia cen i wykresy · wskaźnik okazji · ciche godziny · ocena AI · wykrywanie scamu · Telegram/SMS · wyszukiwanie po zdjęciu · konto i synchronizacja · eksport CSV · inne serwisy.

## 12. Decyzje do potwierdzenia

1. Limit obserwacji w MVP — proponuję **20**.
2. Szybkie dodawanie z wyszukiwarki serwisu (F3) w MVP — **zalecam tak**, najbardziej upraszcza start.
3. Minimalny interwał — proponuję **5 min** (ograniczenie ryzyka blokady przez serwisy).
4. Retencja ofert — proponuję **30 dni**.
5. Godzina zestawienia dziennego — proponuję **8:00**, edytowalna w ustawieniach.
